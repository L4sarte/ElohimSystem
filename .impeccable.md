# Elohim Import ERP — Design Context

## Design Context

### Users
Internal staff of Elohim Import, a perfume & decants boutique operating bimonetary (ARS/USD).
Admins and vendedores use the system daily at the counter — POS with barcode scanner and
bimonetary billing — plus managing stock, JIT decant fractionation, WhatsApp orders (Kanban),
purchases/imports, treasury, and financial reporting. Spanish-first UI. Speed matters: the
POS, omnibar, and keyboard shortcuts (N/I/G) are the primary work surfaces.

### Brand Personality
Premium, precise, trustworthy. The interface should feel like a high-end perfume house:
dark, green-gold, refined serif display accents over a clean geometric sans. It should
evoke confidence and control — the tool behind a luxury retail operation.

### Aesthetic Direction
- **Theme**: Dark-only by design. `#08130E` background, `#13261E` surfaces, `#1B362A` borders,
  `#D0A96B` gold as the brand accent, `#F4F1EA` cream for high-emphasis text.
- **Type**: Playfair Display (display/serif, headings) + Plus Jakarta Sans (UI/body).
- **Density**: Data-dense tables and panels, but with an intentional spacing rhythm —
  luxury house meets operational terminal.
- **Print**: Receipts and PDF reports force a clean black-on-white light treatment.
- **Anti-references**: Generic SaaS blue, light-mode default, toy-like/playful decoration,
  AI-slop gradients and glassmorphism.

### Design Principles
1. **Gold is earned** — gold (#D0A96B) marks primary actions, brand, and money moments;
   green tones carry data and status.
2. **Dark, always** — the dark palette is the identity, not a preference toggle.
3. **Density with breathing room** — dense data, varied spacing, no monotone padding.
4. **Bimonetary clarity** — currency (ARS/USD) and exchange context must never be ambiguous.
5. **Speed is luxury** — POS and omnibar interactions must feel instant; keyboard-first.

### Accessibility Target
WCAG 2.1 AA (contrast ≥ 4.5:1 for text, visible focus, full keyboard navigation,
labeled form controls).
